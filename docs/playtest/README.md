# SDP Multi-Wallet — Playtest Materials

Guides for testing the multi-distribution-account feature on the demo instance.

- **[PLAYTEST-GUIDE.md](PLAYTEST-GUIDE.md)** — end-to-end test flows: what to exercise, expected behavior, and what to report.
- **[USER-GUIDE.md](USER-GUIDE.md)** — step-by-step user guide with screenshots (sign-in → switching accounts → sending a disbursement → managing accounts).
- **[ngo-one-disbursement-sample.csv](ngo-one-disbursement-sample.csv)** — a working recipient file for the "New disbursement" flow.

> Demo login credentials are provided in the playtest invite message (kept out of this repo). The demo runs on Stellar **testnet** — no real funds are involved.
